# Bansil Patel - Portfolio Website

A modern and responsive portfolio website showcasing my frontend development skills and projects.

## 🔗 Live Demo
[View Portfolio](https://patel-bansil.github.io/My_Portfolio/)

## 🛠️ Built With
- HTML5
- CSS3
- JavaScript
- Libraries:
  - GSAP (animations)
  - Typed.js (text animation)
  - Shery.js (mouse effects)
  - Lenis (smooth scroll)

- 🌓 Dark/Light Theme
- 📱 Fully Responsive
- 🖱️ Custom Mouse Follower
- 🎯 Magnetic Effect on Buttons
- 📜 Smooth Scrolling
- ⚡ GSAP Animations
- 📝 Contact Form
- 🎨 Modern UI Design
